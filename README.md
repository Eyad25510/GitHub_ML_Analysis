# GitHub Machine Learning Analysis

## Project Overview

This project analyzes GitHub repository data using Python and data analysis techniques.

The main goal is to explore repository information, identify patterns, and create meaningful visualizations from the collected GitHub data.

## Project Files

- `GitHub_Machine_Learning_Analysis.ipynb` — Main analysis notebook.
- `TASK_2.ipynb` — Additional analysis tasks.
- `github_projects.csv` — GitHub repository dataset in CSV format.
- `github_projects.db` — SQLite database containing the project data.
- `VISUALIZING/` — Folder containing the generated visualizations.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SQLite
- Jupyter Notebook
- Git & GitHub

## Analysis

The project includes:

- Data exploration and cleaning
- Analysis of GitHub repositories
- Repository comparisons
- Data visualization
- Identification of important patterns and insights

## Visualizations

The `VISUALIZING/` folder contains visual outputs created during the analysis.
